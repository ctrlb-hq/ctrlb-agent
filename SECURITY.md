# Security

Report vulnerabilities privately through this repository's [Report a vulnerability](https://github.com/ctrlb-hq/ctrlb-agent/security/advisories/new) form (GitHub private vulnerability reporting). Do not open a public issue with sensitive details.

The scope is this repository's Claude Code and Codex hooks, installers, and redaction of session content and credentials. Include the affected version, operating system, Python and agent versions, steps to reproduce, expected and actual behavior, and a minimal synthetic example. Do not include real keys, tokens, configuration files or session transcripts.
